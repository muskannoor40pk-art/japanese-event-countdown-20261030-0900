## Overview
This project provides a clean, high-performance countdown timer designed specifically for the Japanese market. It features a responsive layout, a structured event agenda, and a seamless subscription mechanism—all encapsulated in a lightweight, single-file architecture. Perfect for marketers and developers needing a quick, beautiful deployment for upcoming Japanese-language product launches.

## Features
*   **Live Countdown Timer:** Real-time precision countdown tailored to JST (Japan Standard Time).
*   **Event Agenda:** Clear, chronological display of event milestones.
*   **Subscription Form:** Simple integration for lead collection.
*   **Responsive Design:** Optimized for both desktop and mobile viewing experiences.
*   **Zero-Dependency:** Built with pure Vanilla JS, ensuring fast load times and no maintenance overhead.

## Localization Notes
*   **Language:** Content is fully localized in Japanese (ja-JP).
*   **Typography:** Optimized for Japanese readability using system-ui fonts.
*   **Formatting:** Date and time formats strictly follow Japanese conventions (YYYY年MM月DD日).
*   **Directionality:** Optimized for LTR (Left-to-Right) text flow.

*   **HTML5:** Semantic markup for accessibility.

*   **Deployment:** GitHub Pages for free, reliable hosting.
